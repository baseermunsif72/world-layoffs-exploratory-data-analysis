# World Layoffs Exploratory Data Analysis Using MySQL

## 📌 Project Overview

This project explores a global layoffs dataset using SQL in MySQL Workbench. The analysis looks for patterns in layoffs across companies, industries, countries, and time periods.

## 🎯 Project Objectives

- Explore the scale and distribution of layoffs.
- Identify companies and industries with the largest layoffs.
- Compare layoffs across countries and time periods.
- Examine layoffs by company stage and funding status.
- Summarize key findings from the dataset.

## 🛠️ Tools & Technologies

- Database: MySQL
- Development Environment: MySQL Workbench
- Query Language: SQL

## 🔍 Exploratory Data Analysis Process

1. **Data Review:** Examined the dataset structure, columns, and date range.
2. **Summary Analysis:** Reviewed total layoffs and the number of affected companies.
3. **Company Analysis:** Identified companies with the largest layoffs.
4. **Industry and Country Analysis:** Compared layoffs across industries and countries.
5. **Time-Based Analysis:** Explored layoffs by year and month to identify trends.
6. **Company Stage Analysis:** Compared layoffs by company stage.
7. **Key Findings:** Summarized notable patterns found in the data.
